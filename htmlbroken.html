How to Add a Background Color

We use the body selector with the background-color property. Example: background-color:aqua;


CSS Selectors

Selector is for choose element. Example: h1 or body.

CSS Properties

Property change how element look. Example: color or font-size.

CSS Values

Value tell property what is. Example: purple or 45px.

CSS Declarations

A declaration is one style for an element. It has a property and a value. Example: color: purple; changes text color to purple.

Rule-set

A rule-set has a selector and declarations. Example: h1 { color: purple; font-size: 45px; } Selector is h1, declarations change color and size.

Style Sheet

A style sheet is where we write CSS to change how a page looks. It controls colors, fonts, and sizes.

Multiple Style Sheets

Yes, a page can use many style sheets. Later styles can change earlier ones.

Internal vs External

Internal styles are inside <style> in html. External styles are separate CSS files linked to html.

Our Stylesheet

We use an external stylesheet called brokenstyles.css.

!important Rule

!important makes a style stronger than others. Example: color: purple !important; forces text to be purple.
